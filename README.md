# 知行知识库

面向初高中阶段的数学与化学知识库，包含知识点讲解、公式与推导、例题思路、易错点、化学方程式和教材章节检索。

## 在线访问

https://palesquire71029.github.io/zhixing-knowledge-base/

## 部署

本仓库使用 GitHub Actions 自动部署 GitHub Pages。将网站文件提交到 `main` 分支后会自动触发部署。

- 入口文件：`index.html`
- 部署工作流：`.github/workflows/pages.yml`
- 内容目前内置于入口页面，后续可逐步拆分为独立的数学、化学数据文件。
